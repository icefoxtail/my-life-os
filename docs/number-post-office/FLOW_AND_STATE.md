# 숫자 배달 우체국 — 상태·입력 계약

## 세 주문의 배달 루프

`진입 → 보관된 주문 복원 또는 새 주문 → 물건 싣기/내리기 → 확인 → 상자 닫기 → 차 이동 → 친구 수령 → 다음 주문 → 세 곳 완료`

각 주문 상태는 `SELECTING`, `DELIVERING`, `DELIVERED`이다. 오답은 `SELECTING`을 유지하고 피드백만 바꾼다. `DELIVERING`에는 물건 이동·묶기·되돌리기를 받지 않는다. `FINISH`는 `DELIVERING`에서만 한 번 실행되며 다음 주문으로 자동 진행하지 않는다. 완료 화면의 명시적인 버튼으로만 이동한다.

## 수량 계약

- 모든 물건은 미션에 포함된 고유 ID 하나를 가진다.
- `positions[id]`는 창고 `-1` 또는 차 `0`, `1`이다. 물건 복제나 소실은 없다.
- 정답은 화면 숫자나 클릭 횟수가 아니라 실제 ID의 위치와 종류로 계산한다.
- 열 묶음은 같은 종류·같은 차의 서로 다른 ID 정확히 10개를 가리킨다.
- 묶기/풀기/차 간 이동은 전체 수량을 보존한다.
- 주문 수량보다 창고 재고가 많아 과다 적재를 직접 수정할 수 있다.
- 두 차 자유 분배는 합이 맞고 두 차가 사용되면 모두 인정한다. 총량 1이면 한 차만 사용한다.
- 비슷하게 나누기는 두 차 수량 차이가 0 또는 1인 모든 분배를 인정한다.

## 입력

| 입력 | 결과 |
|---|---|
| 창고 물건 탭 | 현재 선택한 차에 싣기 |
| 짐칸 낱개 탭 | 창고로 내리기 |
| 물건 끌기 → 차/창고 | 해당 위치로 이동 |
| 물건 끌기 → 다른 곳 | 취소, 기존 위치 보존 |
| 열 개 묶기 | 현재 차의 같은 종류 낱개 10개를 묶음으로 표시 |
| 묶음 탭 | 낱개 10개로 풀기 |
| 되돌리기 | 직전 수량·묶음 변경 한 건 되돌리기 |
| 다시 담기 | 원래 준비된 상자로 복원, 되돌리기로 회복 가능 |
| 주문 카드 탭 | 수량을 실제 그림으로 펼치기, 상태 변경 없음 |
| 출발 | 조건이 맞으면 배달, 아니면 현재 짐 보존 |

포인터 이동은 10 CSS px 이후 드래그로 취급한다. primary pointer 하나만 수락한다. pointer capture는 취소/종료 시 해제한다. `pointercancel`, `lostpointercapture`, `blur`, `visibilitychange`, `resize`, `orientationchange`는 드래그를 취소한다. 취소 뒤 뒤늦게 발생한 호환용 click도 억제한다. 동일 ID의 짧은 중복 입력은 억제한다. 완료·다음 버튼에도 전환 잠금을 적용한다.

각 배달 시작은 별도의 토큰을 받는다. 도착 건너뛰기·같은 주문 다시하기·나가기를 했으면 이전 배달의 남은 애니메이션 타이머는 새 판을 완료시키지 못한다. 배달 장면 중 외부 부모 설정이 바뀌면 결과 화면을 먼저 보여 주고, 다음 주문 버튼에서 새 설정의 보관된 주문을 연다.

## 복원

`localStorage`의 모드·수량 범위별 세 주문과 현재 위치를 저장한다. 모든 저장 입력은 버전·미션 생성 인자·고유 ID·차 번호·묶음 불변식으로 검증하고 재구성한다. 손상된 저장은 새 주문으로 안전하게 시작한다. 배달 도중 나갔다 다시 오면 적재한 상자를 보존한 `SELECTING` 상태로 돌아온다. 완료된 주문은 수령 화면으로 복원한다.

저장 공간 또는 접근이 막혀도 메모리에서 놀이가 계속된다. 해당 상황에는 기기에 저장하지 못한다는 짧은 안내를 남긴다. 다른 놀이로 나갈 때 저장하며 모든 타이머·이벤트·음성·드래그 잔여물을 제거한다.

읽기는 되지만 쓰기만 실패하여 예전 저장본이 남는 경우에도, 같은 페이지의 해당 키에 최신 메모리 snapshot이 있으면 그것을 먼저 복원한다. 읽는 쪽에는 복사본을 전달한다. 실제 저장 쓰기가 거부된 상황의 페이지 전체 새로고침까지 메모리가 유지되는 것은 아니다.

## 소리와 그림 대체

공용 `gameOptions.say`를 먼저 사용하여 부모의 전체 음성 설정을 따른다. 공용 콜백이 없는 독립 실행에서는 기존 `SihyeonVoice.speak`를 사용한다. 실패/미지원/시간 초과는 놀이 상태를 바꾸지 않는다. 주문 그림·실제 수량 펼치기·손 시범은 소리와 독립적으로 동작한다. 게임 안의 음소거와 다시 듣기도 제공한다. 버튼 연타로 음성이 중첩되지 않도록 기존 발화를 중지하고 새 안내를 재생한다.

이미지 로딩 실패는 카드·물건·동물·차와 이동 중 잔상 모두에서 이모지로 대체한다. 자산 로딩 성공을 수량 변경이나 배달 완료의 조건으로 삼지 않는다.
