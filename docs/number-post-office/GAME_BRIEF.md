# 숫자 배달 우체국

## 놀이 목표와 범위

동물 친구가 부탁한 물건을 창고에서 직접 세어 차에 싣고, 배달해 친구가 받는 모습을 본다. 객관식 숫자 맞히기와 달리 고유한 물건을 실제로 옮기고 다시 꺼내 수량을 구성한다. 제한 시간, 벌점, 강제 난도 조절, 광고, 학습 능력 판정은 없다.

기준: 사용자 제공 통합 계획 v2의 07·12·17절 및 이번 직접 구현 요청. 기존 `SihyeonGames` 등록 방식을 유지한다. 이번 사용자 지시가 TTS를 명시적으로 허용하므로 기존 `SihyeonVoice.speak`를 재사용한다.

## 네 가지 추천 놀이

| 모드 | 실제 행동 | 완료 계약 |
|---|---|---|
| 4세 | 한 종류 물건을 하나씩 싣고 빼기 | 요청한 종류와 수량이 일치 |
| 5세 | 두 종류를 각각 담기, 이미 담긴 물건에 부족한 양 채우기 | 두 종류 모두 요청량과 일치 |
| 6세 | 열 개를 묶고 풀기, 세 주문 중 배달 순서를 선택하기 | 총량을 보존하면서 각 주문 충족 |
| 7세 | 두 차에 나누기, 자유 분배와 비슷하게 나누기 | 정확한 총량 및 그림으로 제시한 분배 조건, 여러 유효한 해법 인정 |

연령은 숫자 상한이 아니다. 모든 모드에서 `1~10`, `11~15`, `16~20`, `21~30`을 선택할 수 있다. 두 종류를 요구하는 5세도 총량 1인 경계 사례에서는 한 종류만 사용한다. 선택한 수량 범위는 연령과 독립적으로 저장된다. 화면의 모드와 수량 선택을 바꿔도 이전 상자는 모드·범위별로 보관한다.

## 화면과 입력

그림·음성 주문, 창고, 현재 차의 짐칸, 큰 출발 버튼이 핵심이다. 낱개는 열 개씩 두 줄 다섯 칸에 놓고 다음 열 개는 페이지로 넘긴다. 30개를 한 화면에 축소하지 않는다. 폰 세로는 창고와 짐칸을 위아래에, 폰 가로는 좌우에 두고 행동 버튼을 오른쪽으로 옮긴다.

탭으로 싣기/내리기가 기본이며 끌기는 선택 사항이다. 물건은 놓기를 마쳤을 때만 이동한다. 화면 밖 놓기, 포인터 취소, 두 번째 손가락, 회전, 앱 숨김은 수량을 바꾸지 않는다. 모드가 바뀌면 현재 주문을 저장하고 새 모드의 보관된 주문을 연다.

## 피드백과 안전

부족/과다한 종류를 그림으로 표시하고 직접 수정하게 한다. 정답을 자동으로 채우지 않는다. 주문 카드를 누르면 실제 물건 수만큼의 큰 주문 그림을 열 수 있다. 소리가 꺼졌거나 재생되지 않으면 손→물건→짐칸 그림 시범을 사용할 수 있다.

성공하면 상자를 닫고 차가 이동한 뒤 동물이 물건을 받는다. 결과 화면은 다음 주문, 같은 주문 다시하기, 다른 놀이로 가기를 분리한다. 세 곳을 배달하면 배달 도장을 보여 주며, 도장은 학습 평가가 아니다. 아동의 개인정보나 음성은 서버로 전송하지 않는다.

## 자산

6종 단일 물체 SVG, 6종 동물 SVG, 3색 배송차 SVG, 메뉴 카드 SVG를 직접 제작한다. 모든 낱개는 같은 100×100 viewBox, 80×80 안팎의 보이는 범위를 사용한다. 필수 자산은 로컬 파일이며 실패 시 그림 이모지 대체를 제공한다. 동적 주문 음성은 기존 TTS 엔진을 사용하고 그림 안내는 항상 남긴다.

## 검증 경계

수량·상태 불변식, Chromium 마우스/합성 터치, 세로/가로 레이아웃은 실행 증거를 남긴다. 실제 iOS/Android 기기, 스피커 실청취, 시현이의 독립 플레이 관찰은 다른 증거이며 미실행이면 확인했다고 표시하지 않는다.
