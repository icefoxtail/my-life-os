## 검증과 현재 상태

현재: 구현 중. 모델/상태 검사와 실제 Chromium 공개 메뉴·버튼·원본 PNG를 구분한다. 변경된 게임과 공용 시퀀서의 직접 회귀를 유지하며, 기존 검사의 기준을 낮추지 않는다. 제품 의도가 바뀌는 음소거/이어 세기는 기존 검사도 새 계약의 상태 보존과 취소 검증으로 갱신한다.

동일 판본의 유효한 1~4단계 증거는 재사용한다. 물리 기기 터치, 스피커 청취, 시현이의 실제 이해·선호 관찰은 별도 NOT_RUN이다. CI나 소스 해시 일치만으로 교육 효과를 입증했다고 표현하지 않는다.
