공사장에는 기존 7미션의 랜덤 세 문제를 **공사차 연습**으로 보존한다. 기존 복수정답과 안전한 오답 범위는 유지한다. 작업과 자동 보기는 같은 실제 완료 처리를 쓰고, 결과는 수동 다음 선택까지 유지한다. 모든 주문의 다시 듣기와 선택 차량의 실제 역할 설명을 한국어·영어로 제공한다. 다리의 그림은 기존 지게차·덤프 계열 정답도 가능한 낮은 받침과 짧은 부품으로 표현한다.

소방의 기존 4·9·16대와 여덟 단계는 **그림 순서 놀이**로 보존한다. 새 현장 출동에서는 일반·특수 물탱크 2판본 및 사다리 역할 4판본을 허용한다. 역할이 불확실한 굴절 붐 차나 살수도 가능한 차를 불합리한 오답으로 넣지 않는다. 도움 전환은 현재 사건·차량·작업량을 보존한다. 자료 일부 실패 시 가능한 사건만 제공하고, 임의의 차량을 새 역할의 정답으로 대체하지 않는다.

## 현재 판정

### 첫 실제 브라우저와 시각 수리

후보 `0e892efd115b3c4943d61eb88437a9cd06e990ef`에서 공사장 20개 공개 흐름과 소방 여섯 화면의 세 사건은 통과했다. 그러나 실제 PNG에서 공사 작업차가 배경 아래 여백에 뜨고, 산책 중 발이 만든 길을 벗어나며, 소방 사다리가 차체와 떨어지는 문제가 확인됐다. 기능 검사 PASS를 시각 품질 PASS로 확대하지 않았다. 공사 SVG와 차량의 8:5 좌표면 통일, 실제 길을 따르는 발 위치, 소방 사다리 기점의 최소 수리 후 같은 장면을 다시 확인한다.

소방 전체 검사는 후속 retry_case의 Python built-in 콜백 등록 오류로 중단됐다. 일반 함수 콜백으로 고치고 기존에 미수행한 복구/영어/종료 검사를 다시 실행한다. 기존 그림판 회귀도 reload의 소스 응답 본문을 읽는 단계에서 중단돼, SW 차단된 검증 환경에서 브라우저 캐시를 끄고 HTTP 200과 실제 본문 해시를 계속 요구한다. 첫 로그만으로 해당 응답의 status를 304라고 단정하지 않는다.

별도의 기존 숫자 비교 한 항목은 검사 시점에 toast opacity 0을 관측했다. 숫자 제품과 해당 검사기는 직전 운영 판본과 같은 바이트다. 원인을 단정하거나 판정 기준을 변경하지 않고 다음 후보에서 같은 검사를 재관측한다. 원본 실패와 통과 결과, 대표 결함 PNG, raw SHA 및 아티팩트 영수증은 [history/candidate-0e892ef/](stage4-evidence/history/candidate-0e892ef/)에 보존한다.

### 시각 수리 후 후보 검증

좌표 수리를 포함한 모델 검증을 마쳤고 다음 실제 Chromium 검증을 준비했다. 공사장 11개 상태/생명주기 케이스, 소방 165 assertion/group, 기존 차량 판정과 도움 86개 회귀가 통과했다. 이 숫자는 픽셀/교육적 품질 검사 수가 아니다. 보고서는 [stage4-evidence/model/](stage4-evidence/model/)에 보존한다. 독립 정적 검토는 기존 공용 4개 브라우저 검사의 assert/expect를 삭제하거나 완화하지 않았음을 확인했다. 공사차와 그림의 동일 좌표면·실제 SVG 길 안의 발 위치, 소방 사다리 두 레일과 디코딩된 차량 픽셀의 접점을 추가로 검사한다.

새 공개 브라우저 검사는 공사장 20개 시나리오와 소방의 여섯 화면 크기별 세 사건·자료 실패 후 재시도·음성 실패/종료 복구를 포함한다. 공사장은 정상 모션과 브라우저 터치 입력을 사용한다. 소방은 다섯 화면에 모션 축소, 390×844 한 화면에 정상 모션을 사용하고 첫 출동의 중간 위치/픽셀과 도착 위치를 관측한다. 소방은 native click으로 검사하므로 실기기 터치로 확대하지 않는다.

아직 이번 판본의 실제 브라우저·main·운영 PASS를 주장하지 않는다. 작은 화면 수리의 완료 근거는 [RELEASE.md](../small-screen-ui-20261117/RELEASE.md)에 별도로 보존한다.

로컬 Chromium은 OS socket 제한으로 미수행이다. 실제 Chromium은 GitHub Actions에서 수행한다. 물리 기기의 터치감, 스피커 청취, 시현이의 이해·선호 관찰은 미수행이다. 자동 음성 검사는 호출·문장·취소 경로를 확인하며 소리 청취를 대신하지 않는다. 서비스워커가 차단된 브라우저 검사를 설치 앱의 오프라인 캐시 전환 실측으로 보고하지 않는다.
