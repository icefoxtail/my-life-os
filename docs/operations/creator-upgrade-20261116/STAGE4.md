공사장에는 기존 7미션의 랜덤 세 문제를 **공사차 연습**으로 보존한다. 기존 복수정답과 안전한 오답 범위는 유지한다. 작업과 자동 보기는 같은 실제 완료 처리를 쓰고, 결과는 수동 다음 선택까지 유지한다. 모든 주문의 다시 듣기와 선택 차량의 실제 역할 설명을 한국어·영어로 제공한다. 다리의 그림은 기존 지게차·덤프 계열 정답도 가능한 낮은 받침과 짧은 부품으로 표현한다.

소방의 기존 4·9·16대와 여덟 단계는 **그림 순서 놀이**로 보존한다. 새 현장 출동에서는 일반·특수 물탱크 2판본 및 사다리 역할 4판본을 허용한다. 역할이 불확실한 굴절 붐 차나 살수도 가능한 차를 불합리한 오답으로 넣지 않는다. 도움 전환은 현재 사건·차량·작업량을 보존한다. 자료 일부 실패 시 가능한 사건만 제공하고, 임의의 차량을 새 역할의 정답으로 대체하지 않는다.

## 검증 과정에서 발견해 고친 점

### 장면과 실제 차량·사람의 위치

첫 후보 `0e892ef`는 공사 20개 흐름과 소방 여섯 화면의 세 사건을 통과했지만, 실제 PNG에서 공사차가 배경 아래 여백에 뜨고 산책 중 발이 길을 벗어나며 소방 사다리가 차체와 떨어지는 문제가 드러났다. 기능 PASS를 시각 품질 PASS로 확대하지 않았다.

공사 SVG와 차량을 같은 8:5 좌표면에 놓고, 산책 중간과 끝의 두 발을 실제 만든 길 안에 맞췄다. 소방 사다리 기점은 차량 원본 픽셀에 연결하고, 기존 흰 배경이 있는 특수판에서도 레일이 끊기지 않도록 같은 좌표면의 전경에 표시했다. 실제 PNG와 SVG/차량 픽셀 접점을 함께 확인했다.

후보 `ce95f961`의 독립 검토자는 공사 PNG 7장과 소방 PNG 6장을 실제로 열어 이 문제의 해소를 확인했다. 최종 후보에서 추가로 소방서 간판의 빨간 십자를 시설 이름으로 바꾸고, 390×844·320×568·640×360의 실제 PNG 3장에서 표기와 기존 배치를 확인했다. 마지막 제품 변경은 이 표식 한 곳뿐임을 Git diff로 검증해 이전 기하·사다리 증거의 재사용 범위를 분명히 했다.

### 검사 도구의 실패와 숫자 안내 관측

소방 첫 전체 실행은 Python built-in 콜백 등록 오류로 자료 재시도/종료 복구 전에 멈췄다. 일반 함수 콜백으로 고친 뒤 미수행 항목까지 실제로 통과했다. 그림판 회귀는 reload 응답 본문을 읽는 단계에서 중단돼, 기존 SW 차단 환경에서 브라우저 캐시를 끄고 HTTP 200 및 원본 SHA 일치를 계속 요구했다. 첫 로그에 HTTP status가 없어 304였다고 단정하지 않았다.

기존 숫자 놀이 검사에서는 짧은 안내 문구의 computed opacity 0을 두 후보에서 관측했다. 숫자 제품은 이전 운영과 같은 바이트였다. 검사기의 외부 왕복·고정 대기 대신 실제 탭과 같은 iframe 작업에서 200ms 이상·1000ms 미만의 표시를 관측하도록 바꾸고, 기존 단언 30개와 시나리오 14개를 유지했다. 문구·시간 조건 2개와 최초/첫 rAF/최종/촬영 전후의 시간·inline/computed opacity 기록을 추가했다. 제품 opacity, CSS 전환, 2300ms 숨김 타이머와 탭 횟수는 바꾸지 않았다.

후보 `1453d26`에서 14개가 통과했고 이전 실패 영역의 실제 PNG 3장에 안내가 온전히 보였다. 최종 후보에서도 같은 14개가 통과했다. 새 기록에는 큰 rAF 간격이 있지만, 이전 실패에는 시각과 inline opacity가 없으므로 과거 원인을 외부 관측 지연 또는 CSS 전환 중 하나로 소급 확정하지 않는다.

공사 검사는 정상 모션과 공개 버튼의 브라우저 터치 입력을 사용한다. 소방은 다섯 화면의 모션 축소와 390×844 한 화면의 정상 모션을 사용하며, 정상 모션은 물탱크차 첫 출동의 중간/도착 위치와 PNG 한 동작 범위로 확인했다. 소방 입력은 native click이다. 일부 프레임과 선택된 실제 PNG의 검토를 모든 이미지·모든 애니메이션 프레임의 수동 검토로 확대하지 않는다.

실제 PNG를 손대지 않고 보존했으며, JSON은 원본 SHA를 붙여 손실 없이 묶었다. 선택해 검토한 PNG는 Git에 보존한다. 나머지 전체 PNG 묶음은 보존기간 14일의 CI 아티팩트에 있으므로 영구 보존이라고 표현하지 않는다.

로컬 Chromium은 OS socket 제한으로 미수행이며 실제 Chromium은 GitHub Actions에서 실행했다. 물리 기기 터치감, 실제 스피커 청취, 시현이의 이해·선호 관찰은 미수행이다. 음성 호출·문장·취소 검사는 실제 청취를 대신하지 않는다. SW가 차단된 브라우저 검사를 설치 앱의 오프라인 캐시 전환 실측으로 보고하지 않는다.

작은 화면 수리의 앞선 운영 마감 근거는 [RELEASE.md](../small-screen-ui-20261117/RELEASE.md)에 있다. 5·6·7단계는 대기이며 이번 4단계 실행 범위에 포함하지 않았다.
