## 사용자가 경험하는 변화

- **몇 대일까?** 정답 직후 다음 놀이와 다시 세어 보기를 선택한다. 자동 재세기를 기다릴 필요가 없으며, 선택한 재세기 도중에도 멈추거나 다음으로 갈 수 있다. 30대 차량을 순서대로 등장시키는 시작 간격의 총합을 0.9초 이내로 줄였다. 마지막 차량 자체의 등장 애니메이션 시간은 별도다. 차량을 직접 여러 번 눌러도 같은 차량은 한 대로 세는 규칙은 보존한다.
- **짝맞추기** 실제 역할 음성이 끝나면 바로 다음 카드를 고를 수 있다. 음성을 사용할 수 없으면 기존 글 안내를 읽을 시간은 남긴다. 종료 콜백이 오지 않으면 15초 안전 복구로 조작을 되돌리며 기존 음성을 강제로 끊지 않는다.
- **색깔 풍선·소방 출동** 도움 켜짐/스스로 찾기를 고를 수 있다. 기본값은 기존 도움 켜짐이다. 스스로 찾기에서는 선택지의 정답에만 붙던 크기·빛·지연 강조를 없앤다. 목표 색이나 작업 안내는 유지한다. 선택은 게임별로 저장하고 저장이 거부되어도 현재 세션은 유지한다.
- **소방 출동** 정답을 고른 직후 물 효과가 화면 교체로 사라지던 경로를 고친다. 효과는 현재 화면에 붙고 좌표를 맞추며 짧게 표시한 뒤 정리한다.
- **숫자 왕국** 음소거가 이미 말하고 있는 부모 공용 음성 및 iframe 직접 음성도 즉시 중단한다. 다시 켜도 이전 발화는 재개하지 않고 다음 사용자 동작부터 말한다.
- **하루 순서** 정답이 확정되면 다음 놀이와 다시 보기를 즉시 제공한다. 기존 완료 장면은 유지하며, 자동으로 다음 미션으로 넘어가지 않는다. 다음을 고르면 이전 말과 연출을 정리하고, 다시 보기를 여러 번 눌러도 보상은 한 번만 준다. 보상 저장이 실패해도 다음 진행 버튼은 남는다. 긴 완료 말풍선은 장면 안에 배치해 상태·액션 영역을 가리지 않게 하고, 높이가 낮은 가로 화면의 최종 패널은 간격과 아이콘 크기를 줄인다.
- **패턴 기차** 자유 공작에서 객차를 줄이거나 늘린 편집도 되돌릴 수 있다. 잘린 끝 객차와 길이·선택을 복원하며, 저장 후 다시 들어와도 같은 편집 이력을 사용할 수 있다. 기존 version 1 저장과 20개 코스를 유지한다.

## 회귀 검증과 확인 범위

병합 전 최종 판본 `0100787`과 게임 변경 병합 커밋 `23fd7f9`의 운영 URL에서 Creator 검사는 각각 1단계 회귀를 포함한 9개 묶음·81개 시나리오를 모두 통과했다. 운영 검증 run은 `43899131741`이며, 실제 제공된 런타임 파일 12개의 SHA-256 일치와 각 보고서의 공개 URL·페이지 오류 0건을 확인했다. 배포·Playground·차량·Phase 2 필수 검사도 모두 통과했다. 별도 기차 20코스·24검사 및 이야기 21검사는 Creator 81개에 중복 합산하지 않는다.

새 Node 검사들은 실제 제품 핸들러와 필요한 공용 음성 엔진을 실행한다. 타이머·DOM·오디오 콜백은 결정적인 fixture를 사용하므로 실제 기기 검증과 구분한다.

기차의 기존 20개 코스 브라우저 검증은 별도 `Phase 2 browser release`의 기존 fixture에서 계속 수행한다. 새 검사에서는 실제 공개 메뉴의 자유 공작 편집과 저장·재진입을 확인한다.

실제 Chromium 검사는 공개 메뉴와 버튼을 통해 두 화면 방향에서 진행한다. 제공된 코드의 해시를 저장하고 PNG 증거를 남긴다. 음성 요청/중단의 자동 검사는 실제 소리의 청취를 증명하지 않는다. 물리 기기 터치·실제 청취·시현이의 반응 관찰은 미수행이다.

## 구현 과정 이력

아래는 최종 판본을 확정하기 전 발견하고 보완한 검증 이력이다. 현재 운영 상태는 문서 상단과 릴리스 증거를 따른다.

- 하루 순서의 초기 실제 PNG에서 세로 화면의 긴 완료 말풍선이 성공 상태 문구를 가리고, 가로 최종 화면의 버튼 아래가 잘리는 문제를 발견했다. 장면 안으로 메시지를 옮기고 짧은 가로 화면의 완료 패널을 조정했다. 최종 판본에서 말풍선의 비중첩·텍스트 가시성·버튼 크기와 화면 내 배치를 자동 검사하고 실제 PNG도 독립 검토했다.
- 이야기 검사의 초기 실패는 lifecycle 동작 검사에 들어가기 전 페이지 로딩·폰트 준비 대기에서 발생했다. 실패를 면제하지 않았으며, 최종 판본의 재검증에서 lifecycle을 포함한 전체 검사를 통과했다.
