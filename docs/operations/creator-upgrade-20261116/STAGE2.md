이 단계는 1단계 판정·언어 수리를 포함한 최신 판본 위에 적용한다. 1단계 운영 검증이 끝난 뒤 이 단계를 병합한다. 이 문서는 구현 범위이며, 브라우저/운영 완료 선언이 아니다.

## 사용자가 경험하는 변화

- **몇 대일까?** 정답 직후 다음 놀이와 다시 세어 보기를 선택한다. 자동 재세기를 기다릴 필요가 없으며, 선택한 재세기 도중에도 멈추거나 다음으로 갈 수 있다. 30대 차량의 등장 간격도 전체 0.9초 안에 끝나도록 줄였다. 차량을 직접 여러 번 눌러도 같은 차량은 한 대로 세는 규칙은 보존한다.
- **짝맞추기** 실제 역할 음성이 끝나면 바로 다음 카드를 고를 수 있다. 음성을 사용할 수 없으면 기존 글 안내를 읽을 시간은 남긴다. 종료 콜백이 오지 않으면 15초 안전 복구로 조작을 되돌리며 기존 음성을 강제로 끊지 않는다.
- **색깔 풍선·소방 출동** 도움 켜짐/스스로 찾기를 고를 수 있다. 기본값은 기존 도움 켜짐이다. 스스로 찾기에서는 정답만 크거나 빛나거나 뒤늦게 튀는 표시를 없앤다. 선택은 게임별로 저장하고 저장이 거부되어도 현재 세션은 유지한다.
- **소방 출동** 정답을 고른 직후 물 효과가 화면 교체로 사라지던 경로를 고친다. 효과는 현재 화면에 붙고 좌표를 맞추며 짧게 표시한 뒤 정리한다.
- **숫자 왕국** 음소거가 이미 말하고 있는 부모 공용 음성 및 iframe 직접 음성도 즉시 중단한다. 다시 켜도 이전 발화는 재개하지 않고 다음 사용자 동작부터 말한다.
- **하루 순서** 정답이 확정되면 다음 놀이와 다시 보기를 즉시 제공한다. 기존 완료 장면은 유지하며, 자동으로 다음 미션으로 넘어가지 않는다. 다음을 고르면 이전 말과 연출을 정리하고, 다시 보기를 여러 번 눌러도 보상은 한 번만 준다. 보상 저장이 실패해도 다음 진행 버튼은 남는다.
- **패턴 기차** 자유 공작에서 객차를 줄이거나 늘린 편집도 되돌릴 수 있다. 잘린 끝 객차와 길이·선택을 복원하며, 저장 후 다시 들어와도 같은 편집 이력을 사용할 수 있다. 기존 version 1 저장과 20개 코스를 유지한다.

## 회귀 검증

새 Node 검사들은 실제 제품 핸들러와 필요한 공용 음성 엔진을 실행한다. 타이머·DOM·오디오 콜백은 결정적인 fixture를 사용하므로 실제 기기 검증과 구분한다.

| 검사 | 확인 범위 |
|---|---|
| `test-creator-count-pace.cjs` | 30대, 즉시 다음, 선택 재세기·중지, 중복 클릭, 만료 콜백, 회전·종료, 5문제 완료 보상 |
| `test-creator-memory-pace.cjs` | 실제 TTS/MP3 완료 콜백, 미지원·실패·불발 복구, 오답 관찰 시간, 화면 재구성·종료 |
| `test-creator-help-modes.cjs` | 켜기/끄기, 지연 힌트, 저장 실패, 정오답·단계 보존, 물 효과 좌표·수명 |
| `test-creator-number-mute.cjs` | 부모/독립 엔진, 직접 음성 대체 경로, 늦은 onend/onerror, 2D 전환 정리 |
| `test-creator-life-pace.cjs` | 판정 직후 다음 선택, 다시 보기, 이전 콜백, 회전·종료, 6미션 보상 및 저장 예외 |
| `test-creator-train-edit.cjs` | 축소·확장 Undo, 꼬리 객차·선택 복원, 여러 편집 Undo, 저장 복원, 코스 보호 |

기차의 기존 20개 코스 브라우저 검증은 별도 `Phase 2 browser release`의 기존 fixture에서 계속 수행한다. 새 검사에서는 실제 공개 메뉴의 자유 공작 편집과 저장·재진입을 확인한다.

실제 Chromium 검사는 공개 메뉴와 버튼을 통해 두 화면 방향에서 진행한다. 제공된 코드의 해시를 저장하고 PNG 증거를 남긴다. 음성 요청/중단의 자동 검사는 실제 소리의 청취를 증명하지 않는다. 물리 기기 터치·실제 청취·시현이의 반응 관찰은 미수행이다.

3~7단계는 별도 후속 작업으로 남아 있다. 이 변경으로 그 단계들의 완료를 주장하지 않는다.
