# 3단계 검증 원본

이 디렉터리는 후보 판본의 검사, 운영 주소의 검사, 독립 검토와 수정 전 반례를 보존한다.

- `candidate/`: 최종 후보의 21개 새 시나리오, 그림판 기존 연결 7개, Creator 회귀 81개(1단계 52개 포함)의 원본 또는 원본 해시를 포함한 집계와 실행 참조.
- `production/`: 공개 운영 주소의 런타임 5개 해시, 그림판 13개·정비소 8개 원본 보고서, 3단계 전용 전체 GitHub Actions 아티팩트 ZIP, 대표 PNG와 실행 참조. 기존 Creator 운영 회귀 81개와 해당 12개 런타임 해시는 별도 집계에 보존한다.
- `model/`: 그림판 12개·정비소 11개 모델 검사. 정비소에는 다섯 차종의 수리 순서 30조합이 포함된다.
- `review/`: 구현과 분리된 반례·화면 검토. 과거 보고서의 대기 상태와 제한은 당시 상태이며, 최종 후보 gate closure와 운영 검토를 함께 읽는다.
- `history/`: 수정 전 실패의 실제 보고서와 390px 모드 탭 실패 화면. 실패를 최종 PASS에 포함하지 않는다.

`production/creator-stage3-artifact.zip`은 다운로드한 원본 ZIP 바이트 그대로다. 대표 PNG 외의 전체 화면과 원본 보고서도 이 ZIP에 들어 있다. `MANIFEST.json`은 이 디렉터리의 각 파일 SHA-256을 기록한다.

## 범위

그림판 UI는 320×568, 390×844, 640×360, 844×390, 1024×768에서 확인했다. 정비소 8개 시나리오는 소방차의 네 화면 크기와 경찰차·버스·구급차·로켓차의 390×844 흐름이다. 다섯 차종을 모두 네 크기에서 실행한 20개 조합으로 확대해 해석하지 않는다. 새 정비소 브라우저 검사는 고정 화면 크기에서 수행했으며, 크기 변경·회전과 만료 타이머는 모델 검사 범위다.

브라우저의 native 클릭·스크롤·실제 캔버스/SVG·저장 복원을 사용했다. 음성 전송 완료와 저장 오류·구형 저장 데이터는 명시된 fixture가 포함된다. 물리 기기 터치, 실제 음성 청취, 아이 반응 관찰은 NOT_RUN이다. 작품과 차량은 해당 브라우저의 localStorage에 보관하며 기기 간 동기화는 구현 범위가 아니다.
