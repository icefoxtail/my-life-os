## 검증 범위와 후속 관찰

- **6단계 가독성 개선 후보:** 한글 844×390 가로 화면의 그림 카드 안 라벨이 작다. 상단 큰 단어 안내는 보이지만, 언어·생활·돌봄 단계에서 그림과 라벨의 가독성을 함께 높인다.

### 독립 검토 및 첫 브라우저 증거 반영

- PR: https://github.com/icefoxtail/my-life-os/pull/38
- 독립 검토에서 보지 않은 동일 그림의 힌트 노출과 새 공사 차량의 영어 이름 누락을 발견하고, 실제 반례로 수정·재확인했다.
- 첫 Chromium run `43886155541`에서 구조 8장 난이도 버튼을 공용 뒤로 버튼이 가리는 현상을 확인했다. 공개 셸의 세로 모드에 상단 여백을 확보하고 강제 클릭 없는 동일 검사를 다시 실행한다.
- 한글의 28개 초기 브라우저 검사는 통과했지만 PNG 검토에서 3D 그림이 앞쪽 자모에 가리는 사례를 확인했다. 그림 카드의 투영 위치를 toast 아래와 입력 트레이 위로 제한하고, 보너스 그림은 이전 팝업을 정리한 뒤 한 장만 보여 준다. 깊이 검사를 유지하며 실제 WebGL PNG의 그림·라벨 픽셀을 비교하는 검증을 추가했다.
- 보강 후 한글 모델/상태 검사는 470개다. 이 개수는 화면 가시성 PASS를 뜻하지 않으며 PNG와 실제 브라우저 결과를 별도로 확인한다.
- 숫자 브라우저 검사기의 Playwright callback 등록 오류를 수정했다. 제품 동작 실패와 검사 도구 오류를 구분해 기록했다.
- main/운영 반영은 위 수정이 포함된 최종 판본의 브라우저 검증 뒤에 진행한다.
- 두 번째 실제 브라우저에서 차량 10개 시나리오는 통과했다. 숫자 수량/횟수 화면 시나리오도 통과했으나 기존 시작 검사에서 6·8의 `rect2`가 기본 `tall`과 동일한 두 모양을 중복 제시하는 오류를 발견했다. 중복 선택지만 제거하고 1~300의 640개 제시 모양에 수량 보존·셀 유일성·모양 차이를 검증했다.
- 한글의 그림 가림은 PNG에서 해소를 확인했다. 작은 글자는 2D 축소와 WebGL의 sRGB/mipmap 차이로 픽셀 비교가 오탐할 수 있어, 같은 GPU 경로의 기준 그림을 생성하도록 검사기를 수정했다. 판정 임계값은 유지하고 실제/기준 PNG, 점수, 그림·라벨 가림을 의도적으로 넣은 실패 대조군(negative control)을 모두 보존한다. 최종 판정은 재실행 결과를 확인한 뒤 내린다.
