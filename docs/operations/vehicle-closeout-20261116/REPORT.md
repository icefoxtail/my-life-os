## 사용자에게 달라지는 부분

### 차량 표시

현재 차량 138개 이미지의 실제 크기와 alpha≥16 가시 영역을 다시 측정하여 공용 표시 정보와 일치시켰다. 숫자 세기, 기억 카드, 주차장, 공사장, 소방 출동, 코딩 자동차에서 같은 비율·아래쪽 정렬·안전 여백 규칙으로 표시한다. 작은 가로 화면의 주차·소방·코딩 배치와 태블릿 공사장 버튼 잘림, 이미지 오류 시 대체 표시, 코딩 버튼의 움직이는 클릭 영역도 보완했다.

이미지 파일 자체의 변경은 **0개**다. 기존 승인 이미지 **76개**, 현재 선택 manifest, 기존 clean **39개** 선택 규칙을 보존했다. 138개는 이번에 측정·표시 정보를 맞춘 이미지 수이며, 새로 제작하거나 새로 승인한 이미지 수가 아니다. 과거 거절된 대체 이미지의 HOLD 상태를 현재 보존 원본을 제거하는 기준으로 사용하지 않았다.

### Pixi 탈것 만들기

Pixi 8의 영역 밖 포인터 이동을 받고, 드래그를 시작한 포인터가 끝까지 해당 조각을 소유하도록 했다. 다른 손가락의 간섭과 여러 조각의 동시 드래그를 막고, 화면 밖에서 놓은 마지막 위치도 처리한다. Pixi 7 입력 경로도 유지한다.

장면에서 제거된 파티클과 객체의 애니메이션을 정리한다. 로딩 중 닫기, 조각을 붙이는 중 닫기, 완성 애니메이션 중 닫기 뒤에 이전 runtime이 새 화면을 지우거나 뒤늦은 동작을 예약하지 않도록 했다. 완성 안내는 공유 발화 경로를 사용하며 소방차·경찰차·구급차의 한국어/영어 문장을 한 번 호출한다.

기존 내부 진입점을 수리한 범위다. 공개 메뉴 확장은 포함하지 않았다.

## 검증 범위와 후속 구분

실제 휴대전화·태블릿의 손가락 조작과 스피커 청취는 **NOT_RUN**이다. touch는 Chromium의 입력이고 음성은 발화 내용·언어·횟수 probe 검사다. Pixi 7개 시나리오는 7부품 조립, 출동 버튼/완성 안내, 애니메이션 중 종료·재진입에 집중한다. 장식 3개 배치와 출동 애니메이션을 끝까지 본 뒤 자동 다음 차량으로 넘어가는 흐름을 별도의 완주 검사로 세지 않는다.

독립 검토에서 기존 공사장 640×360 중앙 장면 일부와 코딩 390×844 화살표 하단의 잘림도 기록했다. 해당 규칙은 이번 변경에서 수정하지 않았고, 현재 차량 표시·입력 수리와 분리된 후속 UI 개선거리다. 전체 게임 화면의 모든 미관을 새로 완성했다는 의미로 확대하지 않는다.
