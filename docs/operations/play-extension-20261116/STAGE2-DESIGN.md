# 2단계 — 그림으로 비교하고 빼기

## 놀이와 조작

- 위치: 숫자놀이터의 새 카드 하나. 비교하기 / 빼기 두 탭을 제공한다.
- 대상: 기존 4–7세 설정을 사용하며 나이 때문에 0–30 수량을 제한하지 않는다.
- 목표: 좌우 그림을 하나씩 짝지어 어느 쪽이 얼마나 많은지 보고, 일부가 떠날 때 남은 수가 어떻게 바뀌는지 본다.
- 조작: 그림·수·놀이를 고르면 자동 진행한다. 물체마다 누를 필요가 없다. 다시 보기, 소리 끄기, 읽는 방법, 설정, 돌아가기를 제공한다.
- 완료: 짝과 남는 그림 또는 떠난 그림과 남은 그림이 결과 수와 일치한다. 완료 문구와 강조로 알려주며 점수·오답 잠금은 두지 않는다.
- 다시 하기: 선택한 원래 수와 그림으로 되돌아가 자동 재생한다. 비교와 빼기 값은 각각 저장한다.
- 빼기에서 처음보다 많이 떠나는 선택은 비활성화하며 다른 선택값을 몰래 바꾸지 않는다.

## 수량과 화면

- 비교는 좌우 각각 0–30으로 합계 60개까지 표시한다. 같은 순번끼리 자동 짝을 만들고 남는 그림을 구별한다.
- 빼기는 0≤떠날 수≤처음 수≤30이다. 오른쪽 끝부터 기존 그림 노드를 떠난 자리로 이동한다. 남은 그림과 떠난 그림의 합은 항상 처음 수다.
- 작은 세로 화면은 핵심 수·결과·자동 진행을 중심에 두고, 가로 화면은 넓은 놀이 영역과 선택 영역을 함께 쓴다.
- 320×568, 390×844, 844×390, 1024×768에서 주요 버튼은 44px 이상이며 잘림·가림·수평 넘침을 확인한다.
- 기존 꽃 정원의 채우기는 7→10에서 `7 + 3 = 10`, `3송이 더`를 명시한다. 처음 필요한 수와 현재 더 필요한 수를 구별한다. 기존 0→10, 10→20, 20→30, 30→30 규칙을 유지한다.

## 공용 기능과 에셋

- 기존 12개 그림 및 그림판 28개 견본을 사용한다. 새 카드만 코드 기반 SVG로 만든다.
- 공용 숫자말·그림 목록·자동 진행기·음성 엔진·설정·게임 shell의 render/destroy를 사용한다.
- 신규 음성 엔진이나 추정한 녹음 경로를 추가하지 않는다. 동적 안내는 이미 사용 중인 공용 수량 진행기를 통해 요청한다.
- 전용 성우 녹음이 필요하면 비교 안내, 출발/남은 수 안내, 보충수 안내를 별도 녹음 대상으로 삼는다. 실제 스피커 청취는 브라우저 요청 문구 검사와 구별한다.

## 변경과 검증

- 신규: `quantity-change.js`, 같은 이름의 CSS·카드 SVG·독립 Node/Chromium 검사.
- 확장: 공용 수량 모델의 comparison/subtraction, 꽃 정원 보충수, index 등록·정리·로딩, SW 캐시, 기존 CI에 새 검사 연결.
- 독립 계산: 비교 961조합, 유효 빼기 496조합, 불가한 빼기 465조합 및 비정수 입력. 객체의 원본 참조·고유 ID·보존 수량을 확인한다.
- 실제 메뉴: 비교·빼기 대표/경계값, 빠른 선택 취소, 설정 닫기 재개, 음성 실패 시 진행, 저장·재입장, 네 화면 크기를 확인한다.
- 운영 반영 조건: 1단계 운영 확인 후에만 2단계를 main에 병합하고, 배포된 파일과 운영 놀이를 다시 확인한다.
