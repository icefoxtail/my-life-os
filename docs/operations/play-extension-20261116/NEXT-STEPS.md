# 이번 세 단계 다음에 할 일

아래는 후속 작업안이다. 이번에 승인받은 1–3단계의 완료 판정과 별개이며 아직 실행하지 않았다.

## 4순위 — 실제 기기에서 짧게 함께 놀며 조정

형님이 실제로 쓰는 휴대폰 또는 태블릿에서 현재 나이 설정으로 5–10분 정도 확인한다. 평가 대상은 앱의 안내와 조작이다.

1. 숫자나라에서 원하는 놀이를 찾고, 그림판의 내 작품을 선택한다.
2. 선택한 그림과 수가 음성·화면에 함께 나타나는지 실제 스피커로 듣는다.
3. 진행 중 다른 수나 장면을 고르고, 설정을 열었다 닫고, 홈으로 돌아온다. 이전 음성과 움직임이 뒤에 남지 않아야 한다.
4. 같은 기기를 세로와 가로로 놓고 현재 움직이는 그림·식·다시 보기 버튼을 확인한다.
5. 설명을 다시 묻게 된 부분, 누르기 어려운 버튼, 진행이 너무 빠르거나 느린 부분만 짧게 기록한다. 그 결과에 맞춰 속도·안내·배치를 최소 조정한다.

자동 브라우저의 문구 요청·완료/실패 검사는 실제 스피커 청취와 다르다. 물리 기기·실제 음성 항목은 직접 확인하기 전까지 NOT_RUN이다.

## 5순위 — 이야기 안내 녹음 보강

현재 공용 음성 경로와 실제 manifest를 유지하면서 네 상황의 짧은 고정 안내부터 정리한다. 후보는 “출동해요”, “돌아와요”, “도착해요”, “함께 나눠요”, “같아졌어요”, “그대로 있어요”이다. 실제 사용하는 문구와 부족한 녹음을 대조한 뒤 필요한 파일만 만든다.

새 녹음은 재생 품질·숫자와 그림의 동기화를 확인하고 manifest에 실제 key와 파일을 등록한 다음 연결한다. 존재하지 않는 mp3 경로나 임시 음성 엔진은 넣지 않는다.

## 6순위 — 좋아하는 그림으로 바로 이어 놀기

실사용에서 자주 고르는 그림과 놀이가 확인되면, 최근에 하던 작품·이야기로 돌아가는 짧은 진입 동선을 검토한다. 기존 메뉴와 모든 수 선택을 유지하며 새 기능 범위는 관찰 결과로 정한다. 현재 구현 범위에는 포함하지 않는다.
