**그림과 숫자를 고르면 바로 자동으로 세기 시작해요.** 아이는 원하는 그림과 수를 고르고, 강조되는 그림과 들리는 숫자를 함께 따라가면 됩니다.

## 1. 경찰차 9대, 소방차 15대를 만들어요

**들어가기: 숫자놀이터 → 내가 만드는 숫자놀이**

1. 큰 그림 옆의 **그림 고르기**를 누르고 **경찰차**, **소방차**, **사과** 등 원하는 그림을 고릅니다.
2. **0–10 / 11–20 / 21–30**에서 범위를 고른 뒤 원하는 숫자를 누릅니다. 예를 들어 경찰차와 **9**를 고르면 경찰차 9대가 나타나고 자동으로 셉니다. 소방차 15대는 **11–20 → 15**를 고르면 됩니다.
3. **하나·둘**은 “하나, 둘, 셋…”, **일·이**는 “일, 이, 삼…”으로 읽습니다. **↻ 다시 세기**를 누르면 처음부터 다시 셉니다.

**−1 / +1**로 수를 하나씩 바꿀 수 있습니다. **0**은 해당 그림이 하나도 없는 상태를 보여 줍니다. 화면에 표시된 전체 수와 지금 세는 숫자를 함께 보세요.

## 2. 내가 색칠한 그림으로 숫자놀이를 해요

**들어가기: 즐거운놀이터 → 매직 그림판 → 색칠 팡팡**

1. **색칠 그림**에서 도안을 고르고, **색깔 고르기**에서 색을 골라 그림의 칸을 칠합니다.
2. 추천 색상 예시는 **참고 그림**에서 봅니다. **내 그림 보기**를 누르면 색칠하던 화면으로 돌아옵니다. 예시를 보는 동안 내가 칠한 색은 그대로 유지됩니다.
3. **내 그림 숫자 놀이** 버튼이 활성화되면 누릅니다. 내가 칠한 그림이 **내가 만드는 숫자놀이**로 연결됩니다. 원하는 수를 고르면 같은 색의 내 그림을 그 수만큼 보여 주고 자동으로 셉니다.

참고 그림의 색을 따라 칠해도 좋고, 아이가 원하는 색으로 칠해도 좋습니다.

## 3. 열 칸씩 꽃정원을 만들어요

**들어가기: 숫자놀이터 → 열 칸 꽃 정원**

꽃 그림을 고르고, 가운데 큰 숫자 버튼을 눌러 **0~30송이** 중 원하는 수를 고릅니다. 화면의 숫자 바로가기나 **＋ / −**도 사용할 수 있습니다.

| 모드 | 이렇게 놀아요 |
|---|---|
| **내 숫자** | 내가 고른 수만큼 꽃을 보여 주고 자동으로 셉니다. |
| **자유 정원** | **＋ / −** 또는 숫자 선택으로 꽃을 더하거나 덜며 정원을 바꿉니다. |
| **열 칸 채우기** | 고른 수에서 다음 열 칸이 찰 때까지 꽃을 자동으로 더합니다. |
| **두 색 꽃** | 두 꽃 색 옆의 **＋ / −**로 색별 개수를 바꿉니다. 전체 꽃 수는 그대로 유지됩니다. 이 모드의 전체 수는 가운데 큰 숫자 버튼에서 고릅니다. |

**15송이에서 20송이까지:** 숫자 **15**와 **열 칸 채우기**를 고르면 **고른 수 → 채울 수: 15 → 20**이 표시됩니다. 이미 있는 15송이에 이어 **16, 17, 18, 19, 20**을 세며 꽃이 더해집니다. 처음 고른 15와 채운 결과 20을 구분해 볼 수 있습니다.

작은 화면에서는 화단 안을 스크롤해 다른 열 칸 묶음도 볼 수 있습니다. 자동으로 셀 때는 현재 꽃이 있는 화단을 따라 이동합니다. **되돌리기**는 이전 선택으로, 위쪽 **↻** 버튼은 처음부터 다시 세기로 돌아갑니다.

## 4. 그림을 더하고 똑같이 나눠요

**들어가기: 숫자놀이터 → 그림으로 더하고 나누기**

### 더하기

**＋ 더하기**를 고릅니다. 식의 첫 번째 숫자 자리를 누르고 그림과 수를 고른 다음, 두 번째 숫자 자리도 같은 방법으로 고릅니다. 각 그림을 누르거나 **그림 바꾸기**를 누르면 그림을 바꿀 수 있습니다.

예를 들어 **경찰차 9대 + 소방차 6대**를 고르면 전체 15대가 나타나고 자동으로 셉니다. 결과는 **모두 15**로 표시됩니다. 두 수의 합은 **30까지** 만들 수 있습니다.

### 똑같이 나누기

1. **÷ 똑같이 나누기**를 누르고 나눌 그림과 전체 수를 고릅니다. 예: **사과 15개**.
2. **몇 곳에 나눌까요?**에서 **4**를 고릅니다. 식의 **곳 ▾** 숫자 버튼으로도 나눌 곳을 고를 수 있으며, **1~6곳**을 선택할 수 있습니다.
3. 그림을 한 바퀴씩 자동으로 나눠 줍니다. **15 ÷ 4**의 결과는 **한 곳에 3개씩, 남은 것 3개**입니다. 네 자리의 같은 수와 따로 남은 그림을 함께 확인합니다.

**↻ 다시 세기 / ↻ 다시 나누기**로 같은 선택을 다시 볼 수 있습니다. 다른 그림이나 수를 고르면 새 선택으로 바로 시작합니다.

## 공통 버튼과 음성 확인 범위

- 숫자놀이 화면의 **🏠** 버튼은 숫자놀이터로 돌아갑니다.
- **스피커** 버튼으로 소리를 켜거나 끕니다.
- **나이 숫자·⚙** 버튼에서 4·5·6·7세와 안내 음성 언어를 고릅니다. 나이와 관계없이 원하는 수를 선택할 수 있습니다. 한국어의 읽는 방식은 **하나·둘 / 일·이**로 고릅니다.

음성 자동 검증은 화면의 수량·강조와 요청된 읽기 문구를 대조합니다. **실제 휴대폰 스피커로 소리를 듣고 발음·음량을 확인하는 검증은 아직 실행하지 않았습니다.**
