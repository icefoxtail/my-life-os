## 고정 계약

- 새 놀이도 기존 SihyeonGames render/destroy와 게임 shell을 사용한다.
- 전체 수량 N과 현재 센 수 k를 구분한다. 선택한 N은 세는 중에 바뀌지 않는다.
- 숫자·그림·읽기 방식 변경 및 이탈은 이전 음성·타이머·늦은 콜백을 취소한다.
- 기존 SihyeonVoice를 사용한다. 새 합성 엔진이나 존재하지 않는 녹음 경로를 만들지 않는다. 숫자말은 고유어/한자어/관형형을 구분한다.
- 덧셈 합은 30 이하. 나누기 그룹 수는 1–6. floor(N/g)만 각 그룹에 배분하고 나머지는 별도 보관한다. 나머지 때문에 그룹별 개수를 다르게 만들지 않는다.
- 0은 빈 집합, 0으로 나누기는 허용하지 않는다. 수량은 나이와 별도로 선택한다.
- 기존 저장 작품과 다른 게임/별도 진행 브랜치를 보존한다.

## 필수 검증

- 0–30 수량과 숫자말, 유효한 덧셈/분배 조합의 독립 정수 검사.
- 실제 메뉴 진입, 자동 실행, 변경/취소/이탈, 빈 집합, 새로고침 보존, 영어 모드 및 소리 실패 복구.
- 320·390px 세로, 844×390 가로, 태블릿/데스크톱. 물체·버튼·선택 수량이 보이고 가로에서 선택판이 측면으로 이동.
- SVG는 실제 렌더와 저장 판본 호환성 확인. 기존 필수 CI 유지.
- 로컬 Chromium은 socket 권한 제한으로 시작 실패. 이를 우회하지 않고 GitHub Actions Chromium 및 공유 브라우저 운영 화면으로 검증한다. 실제 Android 소리를 들은 검증과 브라우저 API 검증은 구분한다.
