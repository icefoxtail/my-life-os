## 2. 2D 대체 놀이의 실제 기능

`js/engine/webgl-fallback.js`는 외부 라이브러리, 음성, GPU 없이 동작한다.

- 숫자: 두 블록 선택→합치기, 하나 선택→나누기, 원래 합친 수로 분리, 10칸 묶음 그림, 되돌리기, 새 놀이, 1–10/20/50/100 블록 추가. 합쳐도 나누어도 수량 보존. 화면 과밀을 막는 상한은 총량 300, 블록 24개이며 연령에 따라 강제로 낮추지 않는다.
- 한글: 기본 자음 14개×모음 10개의 140음절 조합, 붙이기/떼기/되돌리기/새 놀이. 대표 낱말이 있는 음절에는 그림과 낱말을 함께 표시한다. 모든 음절에 억지 낱말을 붙이지 않는다.
- 새로고침/이탈: 같은 출처 localStorage에 현재 숫자 블록 또는 자음/모음 조합 저장. 접근 거부나 손상된 저장값은 게임을 막지 않는다. 잘못 저장된 수량·분해 이력은 거부한다.
- 음성: 재생 오류가 있어도 화면 안내와 그림으로 진행한다. 소리 끄기와 다시 듣기. 실제 음성 음질이나 운영체제 음성 엔진은 이번 Node 검증의 대상이 아니다.
- 본 앱 iframe에서는 외부 복귀 버튼 하나를 사용한다. 단독 페이지에서는 자체 복귀 버튼을 제공한다.

## 3. 별도 검토 후 추가한 차량 표시 수리

부모 작업자의 독립 리뷰에서 기존 bbox frame의 `width:90%`와 `max-height:88%` 조합이 세로 로켓을 비균일하게 늘릴 위험, 오류로 car.png로 바꿔도 이전 bbox를 쓰는 문제를 제보받아 두 파일을 추가 수정했다.

- `js/vehicle-display.js`: 측정한 alpha bounds를 SVG `viewBox`로 사용하고 `preserveAspectRatio="xMidYMid meet"`로 양축을 같은 배율로 맞춘다. 원본 HTML img와 오류 핸들러는 SVG foreignObject 안에 그대로 두므로 원본 픽셀을 다시 만들지 않는다. 관찰자나 주기적 측정이 필요 없다.
- `js/games/number-count.js`: 대체 이미지가 되면 동일한 프레임의 bbox를 새 이미지 기준으로 갱신한다. 대체 그림도 없으면 자동차 그림 문자로 수 세기를 이어 간다. 기본 검토 완료 39개 차량 pool은 유지한다.
- 로켓의 가시 영역은 362×716, 대체 자동차는 732×342이다. 오류 전환 후 로켓 bbox가 남지 않는 계약 검증을 추가했다.
- 이 추가 작업에서 이미지 파일을 수정한 수는 **0개**다. 실제 픽셀 수정 2개와 129개 자산 감사는 부모 작업자의 별도 기록을 따른다.

### 실제 제품 모듈을 분리한 가벼운 검수 페이지

전체 메뉴의 공유 Chrome 중단과 구분하여, [검수 페이지](../../scripts/qa-legacy-play.html)에서 실제 제품 JS의 공개 `render` API와 실제 숫자 게임 HTML을 불러왔다. `<base href="../">`로 저장소의 실제 이미지·음성을 사용한다. 모듈 내부 상태, 정답, 난수, 완료 여부는 주입하지 않고 화면 버튼과 현재 보이는 주문만 사용했다. 검수용 완료 보상 콜백은 페이지의 숫자 표시만 바꾸며 제품 기록에는 쓰지 않는다. 이 절은 **실제 브라우저 모듈 조작**이며 전체 메뉴 통합 검수나 휴대폰 실기기 검수와 다르다.

## 5. 아직 하지 않은 검수 / 후속 작업

다음은 **통과 표시하지 않는다**. 통합 검수에서 완료되면 실제 실행 근거와 함께 갱신한다.

- 전체 메뉴 통합 상태에서 소방8단계 완주 및 9대/16대 전체 완주. 현재 소방8단계와 재출동은 제품 모듈을 분리한 검수 페이지에서 확인했다.
- 손씻기의 짧은 휴대폰 세로/가로 레이아웃. 데스크톱 가로에서 4단계 조작·오답 수정·완료·카드 영역 보존은 확인했다.
- 새 SVG 차량 표시의 실제 브라우저 비율 확인은 부모 작업자가 이어서 담당한다.
- 실제 WebGL 정상 기기의 3D 경로 및 실제 CDN 실패 상황(현재 경계는 Node 오류 주입 검증).
- 실제 휴대폰의 OS pointercancel/알림·앱 전환/회전, 실제 음성 출력·TTS 실패, 아이의 사용성 관찰.

PR 생성/병합, 최신 main SHA, 운영 배포 확인과 AWCR 기록은 부모 통합 작업에서 수행하며 이 파일은 그것을 완료했다고 주장하지 않는다.
