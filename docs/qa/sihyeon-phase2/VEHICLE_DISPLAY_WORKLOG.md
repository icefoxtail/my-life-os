## 표시 규격

정비 검수에 통과한 파일만 기존 `display_bounds.json`과 `SihyeonVehicleDisplay`의 clean 목록에 포함한다. 원본의 실제 가시 경계는 측정값으로 보존하며, 표시할 때만 경계의 긴 변 기준 2.5%를 사방의 투명 안전 여백으로 둔다. 가시 중심은 경계 중점, 공용 바닥선은 가시 경계의 아래쪽이다. 비행기·회전날개처럼 땅에 닿지 않는 탈것도 아래쪽 가시 경계를 배치 기준으로 사용한다.

SVG `xMidYMax meet`는 하나의 배율로 가로와 세로를 함께 맞춘다. 긴 차는 가로 제한, 높은 차는 세로 제한을 먼저 만나며, 잘리는 확대나 종횡비 변형을 하지 않는다. 남는 가로 공간은 가운데 정렬하고 아래쪽을 맞춘다. 각 게임은 기존 카드/주차칸/무대 영역 크기만 지정하며 차량별 임의 확대값을 새로 추가하지 않는다. 정규화된 이미지에는 이전 게임의 `transform:scale(...)`을 중복 적용하지 않는다.

원래 HTML 이미지와 load/error 동작을 보존한다. 오류 캡처 단계에서 SVG 래퍼를 되돌린 다음 기존 fallback을 실행하므로, 주차장·짝맞추기의 형제 요소 탐색과 공사장의 부모 요소 탐색이 깨지지 않는다. 주차장 드래그 복제본은 이미 정규화된 화면을 그대로 복제하고 다시 이중 정규화하지 않는다.
