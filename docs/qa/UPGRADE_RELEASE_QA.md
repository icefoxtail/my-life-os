이 기록은 코드·모델 검사, 실제 공유 Chromium 조작, 의도적으로 실패를 만든 하네스, 실제 휴대폰 검증을 구분한다. 모델 검사만으로 화면이나 실제 기기를 통과 처리하지 않는다. 병합 SHA와 운영 배포 확인은 PR의 최종 기록 및 작업 체크포인트에 남긴다.

## 구현 범위

보드랜드는 게임 메뉴·실행 연결·스크립트 로딩·설치 캐시에서 제거했다. 기존 게임 파일을 무차별로 지우거나 다른 게임의 자산 목록을 교체하지 않았다.

공용 놀이 설정은 4·5·6·7세 추천과 게임별 수량을 따로 보관한다. 연령 변경이나 오답이 수량을 강제로 낮추지 않는다. 홈에서 연령을 고르거나 부모 대시보드/우체국에서 설정을 바꿀 수 있다. 우체국은 모든 연령에서 1~10, 11~15, 16~20, 21~30을 선택할 수 있고 자동차 세기는 1~5도 별도로 기억한다.

| 우체국 모드 | 구현한 행동 |
|---|---|
| 4세 | 한 종류의 실제 물건을 세어 싣고 꺼내기. 한 번에 한 주문 |
| 5세 | 두 종류의 수량 구성, 이미 담긴 물건에 부족한 수 채우기, 남은 재고 보기 |
| 6세 | 열 개 묶기/풀기와 낱개 구성, 세 친구 중 배달 순서 고르기 |
| 7세 | 두 차에 나누기, 자유 분배/비슷한 분배, 여러 정답 인정, 결과의 합 표시 |

출발은 실제 고유 물건 ID의 종류별 위치로 판정한다. 오답이면 담은 물건을 보존하고 직접 고친다. 배달은 상자 닫기→차 이동→동물 수령→다음 주문/다시하기로 이어진다. 모드·수량별 세 주문을 저장하며, 배달 도중 이탈하면 짐을 보존한 준비 상태로 돌아온다. 제한 시간, 실패 벌점, 강제 난도 하향, 광고, 능력 판정은 추가하지 않았다.

## 실제 브라우저 — 우체국

실행 환경은 공유 Linux Chromium이다. 메뉴, 버튼, 포인터를 직접 조작했다. 세로/가로는 `scripts/qa-responsive.html`의 실제 iframe viewport를 변경했으며 **물리 스마트폰 또는 터치 에뮬레이션이라고 부르지 않는다**.

| 실행 | 관찰 결과 | 증거 |
|---|---|---|
| 독립 4세 1~10 | 공 1·당근 8·곰 인형 1, 세 친구 모두 배달. 과소/과다 수정, 더블클릭 집계, 8개 상태 새로고침 복원 | `post-office-browser-independent.md` |
| 독립 5세 11~15 | 총량 15·14·12 세 주문 전체 완료. 총합이 같아도 종류별 7+8 오류는 거부하고 6+9 수정 후 수령 | 같은 독립 기록 |
| 독립 6세 11~15 | 15·13·15 세 주문 전체 완료. 15를 열 묶음과 낱개 5로 구성 | 같은 독립 기록 |

데스크톱 배송/완료 레이어가 좁아지는 현상은 독립 검수에서 찾아 수정했고, 배송 이동이 화면 재생성 때문에 순간 이동하던 점도 실제 주행 애니메이션으로 보완했다. 작은 세로 화면의 카드 내부 겹침을 막기 위해 창고/짐칸의 최소 높이를 보장하고 작업 영역만 스크롤한다.

## 기존 게임 검수

주차장과 ABC의 운영 결함 재현 및 수정 후 실제 조작은 [기존 게임 보고서](legacy-repairs.md)에 기록했다. 주차장 4/4 완주, 오답/영역 밖 드롭/연타의 복구, ABC A→B→C 완주, 한글 그림 대체, WebGL 없이 한글 2D 자동 진입을 직접 확인했다.

그림판은 경찰차를 검정, 아이스크림을 빨강으로 채운 뒤 도안/자유 모드 왕복·게임 재진입·페이지 새로고침에서 각각의 색을 유지했다. 자유 그림의 무지개 획도 새로고침 후 복원했다. 비동기 복원 순서 역전은 별도 독립 재현으로 찾아 토큰 검증을 추가했다. [자유 그림 복원 화면](integration-browser/art-restored.png)은 상단 버튼 간격 보완 전의 그림 보존 증거다.

소방 재출동, 손씻기 실제 4단계, 공사장 질문, 숫자 2D와 최종 차량 표시의 추가 실제 조작은 아래 최종 검수 추가 기록에서 완료 여부를 확인한다. 코드 수리 사실과 아직 실행하지 않은 조작을 혼동하지 않는다.

## 명시적 한계와 후속

실제 iOS/Android 기기, 물리 손가락 여러 개, OS 알림 중단, 스피커 음질, 시현이의 독립 플레이 관찰은 실행하지 않았다. 이 항목은 브라우저/합성 검증으로 통과 처리하지 않는다. WebGL이 정상인 실기기에서 기존 3D 장면의 회귀도 별도 확인이 필요하다.

90개 기존 배경 결함과 별도 소방 특수 자산, 큰 미디어/음성 체계 재설계는 후속 범위다. 이번 배포에서 원본 전체를 수리했다고 주장하지 않는다. 수량/완료 기록으로 학습 능력 평가를 하지 않는다.

## 최종 검수 추가 기록

- [실패 환경 브라우저 기록](post-office-failure-browser.md): 합성 취소/바깥 드롭/blur/회전/연타/메모리 복귀/배달 중 이탈 7건. 그림 27개가 모두 실패해도 27개 대체 그림과 음성·저장 대체 안내를 표시했고, 실제 공개 출발 버튼을 눌러 14개 수령까지 완료했다.
- [독립 작은 화면 기록](post-office-browser-independent.md): 360×640에서 새 놀이·싣기·내리기·부족 안내·작업 영역 스크롤·11개 그림 안내를 직접 조작했다. 창고/짐칸/출발 버튼의 겹침으로 막히지 않았다.
- [마지막 저장 경계 검토](storage-write-failure-review.md): 읽기 가능한 옛 저장이 남고 쓰기만 거부될 때 우체국과 그림판이 과거로 되돌아가는 두 결함을 최종 독립 검토에서 찾아 수정했다. 같은 원래 재현과 신규 회귀를 독립 담당자가 다시 통과시켰다. 기존 브라우저 보고서의 실행 당시 SHA는 보존하고 이 후속 Node 증거를 따로 연결했다.
- [최종 자동 실행 결과](final-automated-results.json): 11개 검사 명령이 모두 exit 0으로 완료됐다. 이것만으로 실제 기기나 운영 배포를 통과 처리하지 않는다.

나머지 기존 게임 실제 조작 및 차량/그림판의 최종 화면 확인은 해당 담당 검수 기록과 함께 아래에 추가한다. 원격 CI·운영 배포 결과는 PR과 AWCR의 후속 기록에 연결한다.
